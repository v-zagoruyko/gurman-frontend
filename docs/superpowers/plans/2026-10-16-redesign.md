# Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the single-page site with a banquet-first home page and a `/menu/` page of PDF cards, in a new soft burgundy/cream style readable for 50+ on phones.

**Architecture:** Static files only. Shared `styles.css`, two HTML pages, PDFs and photos in `files/` and `assets/`. nginx config stays as is; Dockerfile gains two `COPY` lines. No JS, no build, no new dependencies.

**Tech Stack:** HTML, CSS, PT Serif / PT Mono from Google Fonts, nginx:alpine in Docker. One-off asset prep via `uv run --with pymupdf` (not added to the repo).

**Spec:** `docs/superpowers/specs/2026-10-16-redesign-design.md`

## Global Constraints

- Static only: no JS, no build step, no new dependencies, no form or backend.
- Text on phone: body 19px (1.55–1.65 line height), muted/helper text not below 16px, PT Mono not below 14px. All sizes in `rem`.
- Text contrast not below 5:1. `--gold #A6802C` only for lines and decoration; text gold is `--gold-text #7F5F18`.
- Tokens: `--bg #F7F3EC`, `--card #FFFFFF`, `--line #E2D8C4`, `--ink #2A2320`, `--ink-2 #5D5449`, `--muted #6F6558`, `--wine #6E1220`, `--gold #A6802C`, `--gold-text #7F5F18`.
- Buttons: pill (`border-radius: 999px`), min-height 54–60px, full width on phone, visible focus ring, no hover-only behaviour, no animation.
- Phone numbers and prices use `font-variant-numeric: lining-nums`.
- Phones: 21-75-65 (`+73452217565`, primary), 21-81-15 (`+73452218115`), 99-22-99 (`+79044499299`).
- Allowed occasions: weddings, anniversaries, corporate events only. No "поминки". No invented dish descriptions.
- Unconfirmed values (hall capacities 100 / 50, hours 11:00–00:00, prepayment wording, PDF captions, map coordinates) get an adjacent `<!-- TODO-CONFIRM: ... -->` comment.
- PDF file names are permanent and ASCII: `menu-banquet.pdf`, `menu-caucasian.pdf`. Original `files/menu.pdf` is kept until Viktor confirms removal.
- No commits or pushes unless Viktor asks. Code and comments in English, page copy in Russian.
- New year promo is out of scope: leave an HTML comment slot `<!-- NEWYEAR-SLOT -->` after the header.

## Review Focus

- Page wider than the viewport at 320px (long phone buttons, headings): no horizontal scroll.
- Sticky call bar covering the last content or footer on phone: content must stay reachable.
- A photo or PDF link that 404s after Docker packaging (Dockerfile copies only listed paths).
- Hero photo too small and blurry when stretched full width.
- Compressed PDF unreadable (text or prices blurry) or page split off by one.
