# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Одностраничный сайт банкетного ресторана «Гурман» (Тюмень, ул. Линейная, 66), домен `ресторан-гурман.рф`. Аудитория — взрослые люди, стиль аристократический: бордо + золото, антиква, крупный шрифт. Сайт для мамы Виктора, правки обычно мелкие и точечные.

Это чистая статика: один `index.html` со встроенными `<style>`, без сборки, без JS, без зависимостей и без линтера/тестов. Шрифты (Cormorant Garamond, Literata, Marck Script) грузятся с Google Fonts.

## Команды

```bash
# локальная проверка так же, как на сервере
docker build -t gurman-test . && docker run --rm -p 8089:80 gurman-test   # http://localhost:8089
```

Отдельной dev-сборки нет: можно просто открыть `index.html` в браузере.

Деплой: push в `main` → GitHub Actions (`.github/workflows/deploy.yml`) собирает образ `nginx:alpine`, пушит в GHCR с тегом sha и по SSH обновляет `/opt/apps/gurman` на VPS. Пушить только по явной просьбе: это сразу выкатывает на прод.

## Структура

- `index.html`: боевая страница. Пути `assets/…` и `files/…` относительные.
- `assets/`: фото (`hero.jpg`, `wedding.jpg`, `anniversary.jpg`, `corporate.jpg`). Сейчас там мелкие 398×188 из примеров; заменяются оригиналами с теми же именами, в HTML ничего менять не нужно.
- `files/`: то, что отдаётся ссылками: `menu.pdf`, `new-year-program.jpeg` (афиша программы), `new-year-menu.jpeg` (новогоднее меню). Новогодние картинки намеренно не вставлены в дизайн блока, только ссылками.
- `design/index.html`: исходник дизайн-прототипа (ссылается на `../refs/…`). Опубликован как Artifact на claude.ai (приватный). Это **не** то, что деплоится; production-копия сделана из него обёрткой `<head>` и заменой путей. Правки в дизайн и в `index.html` нужно вносить вручную в оба, если они должны совпадать.
- `refs/`: референсы заказчика (фото зала, новогодние баннеры). Не коммитятся (`refs/` и `design/` решено не коммитить) и не попадают в образ: `Dockerfile` копирует только `index.html`, `assets/`, `files/`.
- `nginx.conf`: статика без SPA-фолбэка (несуществующий путь даёт 404), `/assets/` кэшируется на 30 дней без `immutable`, потому что фото будут заменяться под теми же именами.

## Деплой и инфраструктура

- Сервер: личный VPS 89.111.165.57, `/opt/apps/gurman` (`docker-compose.yml` + `.env` с `IMAGE=…`). TLS и роутинг через общий Traefik (роутер `gurman`, resolver `le`). `mem_limit: 32m`, БД нет.
- Host в compose указан в punycode: `xn----7sbblh9beecscegov.xn--p1ai`. Кириллицу в `Host(...)` писать нельзя. `www.` обслуживает второй роутер `gurman-www` и редиректит 301 на основной домен (`redirectregex`; `$` в compose экранируется как `$$`).
- Домен у регистратора reg.ru. Если сайт «не открывается», сначала проверять DNS через DoH (`curl "https://dns.google/resolve?name=xn----7sbblh9beecscegov.xn--p1ai&type=A"`): на машине разработчика прокси подменяет обычный DNS адресами `198.18.x.x`. Ожидаемая A-запись: 89.111.165.57. NS вида `*.expired.reg.ru` означает, что регистрация домена истекла.
- Референс инфраструктуры: `~/Projects/Personal/boilerplate`; общие правила деплоя пет-проектов описаны в глобальном `~/.claude/CLAUDE.md`.

## Контент: что подтверждено, а что нет

Из баннеров заказчика (надёжно): телефоны 21-75-65, 21-81-15, 99-22-99 (код города 3452), цены новогоднего шоу «Русский шик» — 5 000 ₽ на 18, 19, 25, 26 декабря и 4 000 ₽ в остальные даты, шампанское на велком в подарок, алкоголь свой без пробкового сбора, состав программы.

Взято из каталогов или написано самим Claude, нужно подтверждение у заказчика: вместимость «до 150 гостей», часы «11:00–00:00 ежедневно», описания блюд, банкетных форматов и текст «О ресторане».

Заглушки: блок карты (ссылка на Яндекс.Карты вместо встроенного виджета, нужны координаты), логотипа нет (текстовый вордмарк «Гурман»).

## Правила правок

- Отдельной формы заявки нет, заказ банкета только по телефону; бэкенд не нужен.
- Цифры в телефонах и ценах набирать с `lining-nums`: старостильные цифры Cormorant заказчик отклонил.
- Основной размер текста 18–19 px, контраст высокий: не мельчить ради «красоты».
